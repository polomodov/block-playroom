# Семейная игротека

[Открыть игротеку](https://games.polomodov.tech/block-playroom/). Пятнадцать игр на русском для телефона, планшета и компьютера. В каждой игре не меньше семи уровней. Вся коллекция устанавливается из одного меню и запускается с одной иконки.

## В дорогу

1. Пока есть интернет, откройте игротеку. В меню браузера выберите установку или добавление на домашний экран.
2. Откройте **«Игротеку» с домашнего экрана**, пока есть интернет. Все пятнадцать игр загрузятся вместе. Дождитесь статуса **«Готово к игре офлайн · 15 из 15 игр»**. Если старая версия всё ещё показывает семь игр, закройте её и снова откройте с той же иконки. Текущую партию можно продолжить после обновления.
3. Включите авиарежим, закройте приложение и откройте его снова для проверки.

У каждой игры своё сохранение. В главном меню можно продолжить последнюю партию и увидеть 50 последних результатов со всей коллекции. Поддерживается продолжение старых партий из отдельных версий лабиринта, платформера и раннера, если браузер предоставляет то же хранилище. Очистка данных приложения удаляет локальную историю, сохранения и скачанные игры.

## Разработка

Статический сайт без сборки и внешних зависимостей в браузере. Для запуска из родительской директории используйте `python3 -m http.server 8000` и откройте `http://localhost:8000/block-playroom/`. Сервис-воркеру нужен HTTPS или localhost.

Три аркады входят в репозиторий готовыми к запуску в `games/`. Их исходные репозитории и закреплённые коммиты указаны в `scripts/sync-games.mjs`. Обычный запуск и установка обходятся без обращения к исходным репозиториям. Портреты семьи, панорамы и декорации для других игр взяты из «Блок Аркады» в `games/block-maze/`. При синхронизации платформер и раннер подключают эту графику через `games/classic-arcade-art.js`.

- `node --test tests/*.test.mjs` проверяет механику игротеки, общие сохранения и работу офлайн-пакета.
- `node scripts/sync-games.mjs` воспроизводит встроенные аркады из закреплённых коммитов. Проверка `--check` сверяет снимки с этими версиями.
- Для обновления одной аркады поменяйте её коммит, выполните синхронизацию и обновите перечень офлайн-файлов.
- Встроенная аркада и её отдельная версия на том же домене пишут сохранение под одним ключом (`family-games:/block-maze/:progress:1` и так далее). Поэтому формат сохранения в аркаде нужно менять обратно совместимо и сразу обновлять закреплённый коммит здесь, иначе две версии начнут сбрасывать сохранения друг друга.
- `node scripts/update-offline.mjs` обновляет перечень файлов с контрольными суммами после изменения игр или графики.
- `node scripts/update-offline.mjs --check` проверяет соответствие перечня рабочей версии.
- GitHub Actions запускает модульные и браузерные тесты и обе проверки `--check` при каждом PR и push в main.
- Картинка для превью ссылок лежит в `assets/share/` и в офлайн-пакет не входит.

### Браузерные тесты

Для запуска из корня репозитория нужен Node.js 22 или новее. Тесты сами поднимают локальную копию игротеки. Chromium проверяет настольное управление, а WebKit в профиле iPhone 13 — мобильное.

```sh
cd tests/browser
npm ci --ignore-scripts
npm run install-browsers
npm test
```

Можно выбрать один сценарий или браузер, например `npm test -- catalog.spec.mjs --project=webkit`. Проверка офлайна использует отдельный профиль, загружает только главную страницу, отключает HTTP-сервер и полностью перезапускает браузер. Затем проверяет контрольные суммы файлов и продолжение партии.

Отчёт о покрытии модульными тестами выводит команда `node --test --experimental-test-coverage --test-coverage-exclude='**/tests/**' tests/*.test.mjs` из корня репозитория. Браузерные сценарии выводятся отдельно.

Публикация через GitHub Pages из ветки main. Игровые иллюстрации и локальные шрифты загружаются вместе с игрой. Лицензия шрифта в assets/FONT-LICENSE.txt.
