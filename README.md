# Семейная игротека

[Открыть игротеку](https://games.polomodov.tech/block-playroom/). Четыре игры на русском для телефона, планшета и компьютера. Все работают на одном устройстве.

| Игра | Как играть |
| --- | --- |
| [Два ключа](https://games.polomodov.tech/block-playroom/?game=coop) | Два героя по очереди держат плиты, открывают шлюзы и закрепляют мосты. Чтобы пройти одну из семи комнат, нужно вывести обоих. |
| [Гольф семи миров](https://games.polomodov.tech/block-playroom/?game=golf) | Выберите до четырёх героев и передавайте устройство после удара. Выигрывает тот, кто пройдёт семь лунок за меньшее число ударов. |
| [Куда делся изумруд?](https://games.polomodov.tech/block-playroom/?game=mystery) | Перемещайтесь по плану магазина, осмотрите кассу, мастерскую и архив. Сопоставьте штамп и цвет ленты с приметами помощника, а затем отыщите посылку. Ведьма ходит по расписанию, Мама может стать невидимой. |
| [Гитарная репетиция](https://games.polomodov.tech/block-playroom/?game=rhythm) | Выберите песню, послушайте или посмотрите фразу Паши и повторите её на четырёх клавишах. Точная игра в ритм приносит дополнительные очки. Можно играть без звука. |

## В дорогу

1. Пока есть интернет, откройте игротеку. В меню браузера выберите установку или добавление на домашний экран.
2. Откройте игру **с новой иконки** и дождитесь статуса **«Готово к игре офлайн»**. Одной установки хватает на четыре режима.
3. Включите авиарежим, закройте приложение и откройте его снова для проверки.

У каждого режима своё сохранение. В меню можно продолжить с места остановки или начать новую партию. Последние 50 результатов хранятся на этом устройстве. Очистка данных сайта удаляет историю и сохранения.

## Разработка

Статический сайт без сборки и внешних зависимостей в браузере. Для запуска из родительской директории используйте `python3 -m http.server 8000` и откройте `http://localhost:8000/block-playroom/`. Сервис-воркеру нужен HTTPS или localhost.

- `node --test tests/*.test.mjs` проверяет все четыре игры.
- `node scripts/update-offline.mjs` обновляет перечень файлов с контрольными суммами после изменения игр или графики.
- `node scripts/update-offline.mjs --check` проверяет соответствие перечня рабочей версии.

Публикация через GitHub Pages из ветки main. Игровые иллюстрации и локальные шрифты загружаются вместе с игрой. Лицензия шрифта в assets/FONT-LICENSE.txt.
